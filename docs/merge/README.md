## 一句话结论

预填充相对基线 **+42.6% ~ +54.2%**（70K / 145K token 深度），解码与长上下文检索**无回归**，
用户既有 Tensorninja 拼写启动脚本**无需改动**。

| 指标 | baseline | merged | 变化 |
|---|---:|---:|---:|
| 预填充 @ 70,221 token | 1,507.7 tok/s | **2,325.2 tok/s** | **+54.2%** |
| 预填充 @ 145,240 token | 1,228.8 tok/s | **1,751.8 tok/s** | **+42.6%** |
| MTP3 解码（浅上下文） | 144.4 tok/s | 146.1 tok/s | +1.2%（噪声内） |
| 144K 上下文针探 | 精确命中 | 精确命中 | 无回归 |
| GDN 长输出（10K+ token） | 完成，0 CUDA 错误 | 完成，0 CUDA 错误 | 无回归 |

## 镜像

| 镜像 | 说明 |
|---|---|
| `ninfer-4090-merged:sm89` | 最终构建：基底 + INT8 prefill + SM 自适应 + CLI 兼容层 |
| `ninfer-4090-merged:baseline` | 同基底的纯净构建，仅用于 A/B 对照 |

构建：

```sh
docker build --tag ninfer-4090-merged:sm89 .
```

## 重要提示

- **显存独占**：merged 服务（rk4v4-e8 / 262,144 / 4 路 / vision / MTP）占 **24.8 GB**，
  与另一套 int8 KV 生产服务（~30 GB）**无法在同一张 49 GB 卡上共存**，切换须停旧服务。
- **崩溃假设未复现**：计划中的「GDN 长输出崩溃」未能复现，P0a 应定位为**调优可移植性**而非崩溃修复。
  详见 [融合方案报告 §5.2](多分支源码深度分析与融合方案报告.md)。
- **已知缺口**：上游 `45a5ae57` 的 **GQA attention decode** 波尺寸修正**未移植**（上游实测解码 −38.8%），
  且本 A/B 未覆盖该形状。详见 [融合方案报告 §3.2](多分支源码深度分析与融合方案报告.md)。
- **提示词长度按 token 计**：中文重复文本在此分词器下约 **1.57 字符/token**，按字符估算会高估约 57%，
  容易触发 `context_length_exceeded`。
